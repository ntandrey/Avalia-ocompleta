Este projeto consiste num Guia de Direitos do Consumidor composto por três páginas web desenvolvidas com HTML semântico, sem a utilização de CSS. A primeira página aborda os prazos legais através de tabelas e indicadores visuais, a segunda explora práticas abusivas utilizando elementos multimédia, citações legais e blocos interativos, e a terceira disponibiliza um canal de ouvidoria estruturado com formulários modernos para o registo de reclamações e denúncias.
